# ⚡ spark: Creative Ideation & Project Evolution Engine

`spark` is an engine for lateral thinking, creative synthesis, and high-impact feature evolution. It bridges raw ideas with deep system capabilities, generating non-obvious, wow-factor improvements for projects and codebases.

---

## 🎯 1. Core Principles

1. **Cross-Pollination Over Isolation**: Never brainstorm in a vacuum. Mix existing skills (`sieve` ETL, `scribe` OCR/Vision, `artisan` UI/UX, `keel` Security, `loom` Workflows) with domain challenges to unlock unexpected solutions.
2. **Friction-to-Feature Inversion**: Every pain point, bottleneck, or manual step in a workflow is an unpolished feature waiting to be automated or gamified.
3. **The 4-Lens Ideation Framework**:
   * 🔍 **Deconstruction**: Break the current project into atomic layers (Ingestion, Processing, Persistence, Interface, Security).
   * ⚡ **Lateral Shift (SCAMPER/TRIZ)**: Substitute inputs, Combine skills, Adapt patterns from other domains, Modify scale, Eliminate friction, Reverse assumptions.
   * 🎨 **Aesthetic & Experience Lift**: How can the user be "wowed" at first glance? (Visuals, micro-interactions, dark mode, zero-latency feedback).
   * 🚀 **Autonomous Leverage**: How can local LLMs (Gemma 4 12B) or autonomous subagents run this 24/7 without cloud API costs?
4. **Concrete Markdown-First Blueprints**: Always emit human-readable blueprints with Mermaid architecture diagrams, proof-of-concept code snippets, and phased roadmaps.

## 🧠 2. Ideation Lenses & Methodology

When activated on a user prompt or project:

```
Deconstruct Project ──► Cross-Pollinate Skills ──► Apply 4-Lens Shift ──► Generate Spark Blueprint
(Atomic Analysis)      (Sieve, Scribe, Artisan)   (SCAMPER / Friction)    (Spec + Mermaid + PoC)
```

### Lens 1: Skill Synergy Matrix
Map existing Antigravity skills to the project idea:
- **`sieve`**: How do we make the data pipeline idempotent, schema-validated, and fail-safe?
- **`scribe`**: How can we introduce multimodal vision, OCR, or document intelligence?
- **`artisan`**: How do we elevate the UI/UX to a state-of-the-art, glassmorphism design system?
- **`keel` & `warden`**: How do we enforce security, local privacy, and audit boundaries?
- **`beacon`**: How can we automatically notify or deliver executive digests?

### Lens 2: Provocative "What-If" Probing
Ask 3 high-leverage questions to challenge conventional approaches:
- *"What if this tool ran 100% offline using Gemma 4 12B with zero cloud cost?"*
- *"What if the user never had to click a button, because background events trigger the action proactively?"*
- *"What if we transformed static data into an interactive visual canvas or gamified experience?"*
